# Ortak Oyuncu

İki kişilik online futbol düellosu. İki oyuncu 10 saniyede birer kulüp seçer; iki kulüpte de oynamış bir futbolcuyu ilk yazan turu alır.

A two-player online football duel: both players pick a club in 10 seconds, then the first to name a footballer who played for both clubs wins the round.

- Oyuncu verisi / player data: [Wikidata](https://www.wikidata.org) (CC0)
- Online eşleşme / matchmaking: Supabase Realtime (presence)
